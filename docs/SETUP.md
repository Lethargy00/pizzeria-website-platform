# Setup

## Prerequisites

- **Node.js 26** (Active LTS). `.nvmrc` pins the major: `nvm use` or `fnm use`.
- **pnpm 10.28.0** via Corepack: `corepack enable` (the version comes from `packageManager` in `package.json`).
- Git.

## First run

```bash
pnpm install --frozen-lockfile
pnpm check        # format, lint, typecheck, unit tests, guard-script tests, tenant-guard, boundaries
pnpm test:e2e     # Playwright (no suites yet); first run: pnpm exec playwright install --with-deps
```

`pnpm-lock.yaml` is generated by the `bootstrap-lockfile` workflow on the first push to `main` (agent sessions can't reach npm). If it's missing locally, pull `main` first.

## Commands

| Command                                                      | What it does                                        |
| ------------------------------------------------------------ | --------------------------------------------------- |
| `pnpm build`                                                 | Builds all packages (Turborepo)                     |
| `pnpm lint` / `pnpm format` / `pnpm format:check`            | ESLint / Prettier                                   |
| `pnpm typecheck`                                             | `tsc` for the root config and every package         |
| `pnpm test`                                                  | Vitest unit tests (`packages/*/src/**/*.test.ts`)   |
| `pnpm test:scripts`                                          | `node:test` suites for the guard scripts            |
| `pnpm tenant-guard`                                          | Fails if anything under `tenants/` isn't plain data |
| `pnpm check-boundaries`                                      | Enforces package dependency rules (ADR 0001)        |
| `GITHUB_REPOSITORY=… GITHUB_TOKEN=… pnpm review-gate <pr>`   | Review matrix check for a PR                        |
| `GITHUB_REPOSITORY=… GITHUB_TOKEN=… pnpm touches-guard <pr>` | Checks a PR stays inside its issue's Touches        |

The `pwp` CLI (`new`, `validate`, `dev`, `build`, `audit`, `preview-themes`) arrives in M5.

Dependabot PRs: do not use "Update branch"; comment `@dependabot recreate` instead. See [Dependabot PRs](SECURITY.md#dependabot-prs).
